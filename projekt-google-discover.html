Google Discover Insights

I led a new Google Discover analysis area from discovery to launch. AI-powered topic clusters and an anonymized competitor comparison turned hard-to-evaluate Search Console data into strategic insights for publishers.

[ 00 // Product Profile ]

Google Discover is an important source of reach for publishers. I owned this project end to end, from discovery through launch, and brought a new analysis area to the Trisolute News Dashboard.

  • ProductTrisolute News Dashboard
  • RoleProduct Manager
  • FocusGoogle Discover analytics and AI-powered topic analysis
[ 01 // The Challenge ]

From scattered data points to a strategic view of topics

Google Discover can be an important source of reach for publishers, but raw performance data does not always make it easy to see the bigger picture. Search Console provides the latest 16 months of data. On its own, that rolling window also makes it difficult to keep a continuous history beyond the available period.

The central opportunity was to move beyond individual data points and help publishers understand performance by topic, while retaining the data they had already imported.

[ 02 // A Publisher's Question ]

Example story: From a broad request to a Google Discover strategy

The customer request was broad: “We need more insights into Google Discover.” In discovery, I unpacked what that could mean in practice and translated it into concrete publisher questions. Christmas coverage became a useful example for shaping the analysis.

1

Define what counts as Christmas coverage

I identified that useful topic analysis had to go beyond exact keyword matches. The cluster needed to include semantically related stories such as “Germany's most beautiful Christmas markets”, then make clicks, impressions and CTR readable across the topic.

2

Surface the seasonal comparison and its limit

I brought the seasonal question into the analysis: how did Christmas Discover performance compare over time? The available Google Discover view did not support a comparison of the last three seasons. It only allowed publishers to compare the latest Christmas season, so I made that boundary explicit.

3

Add the competitive perspective

I also identified the value of understanding which publishers performed well on Discover for a topic such as Christmas. The anonymized comparison added that context without revealing exact article or click volumes.

Customers brought the broad need for more Google Discover insights. I did the product work to turn that request into a clear analysis model, define the topic clusters and comparison, and set honest expectations around the data limit.

[ 03 // My Approach ]

AI topic clusters were the core value

I owned the project from discovery to launch. The main value was the AI-powered analysis of article titles. It identified keywords and grouped related coverage into topic clusters, helping publishers interpret performance across a subject area instead of piecing together individual articles and data points.

The feature added value on two further levels. First, the News Dashboard could import the latest 16 months available in Search Console and add a new data block each month. This preserved a continuous history in the dashboard beyond the 16-month window, without retrieving older data from Search Console. Second, an anonymized comparison made it possible to see how publishers performed against one another on a topic level.

[ 04 // Impact ]

Three feature benefits, one positive customer signal

The AI-powered topic analysis was the core benefit. Two complementary capabilities added context and continuity, helping publishers move from isolated metrics to a more useful view of their Discover performance.

Understand topics with AI

AI grouped related article titles into topic clusters, helping publishers assess coverage and performance by subject rather than as separate data points.

Keep a continuous history

Monthly imports retained new Search Console data in the News Dashboard, building an ongoing history beyond its 16-month source window.

Compare performance by topic

An anonymized topic-level comparison showed which publisher performed best on a subject, without revealing exact article or click volumes.
